## 1. 电源与主控板（BCP 板）硬件设计

**功能描述**：BCP 板是整车供电与控制的核心电路板。电源部分采用 2 节 18650 电池供电（实测 8.4V），经 PMOS 防反接进入 Mini 降压模块（5V），再经 AMS1117-3V3 输出 3.3V；5V 供给四个 TT 马达、语音模块与舵机驱动，3.3V 供给 ST 最小系统板、自动下载电路及所有逻辑通信高电平。控制部分采用 STM32F103C8T6 最小系统板，引出 UART1（自动下载/上位机通信）、SPI2（PS2 手柄，软件 NSS）、UART3（舵机驱动）、UART2（语音模块），以及 TIM3/TIM4 各四个 PWM 通道分别控制左、右两侧 TT 马达。

**开发历程**：

- **9.18 晚**：硬件歪比巴卜同学根据 2026CRTC 参赛手册 V1.3 所列元器件绘制第一版 BCP 板。

  ![BCP 板图一](图片和附件/IMG_7033.png)

  ![BCP 板图二](图片和附件/IMG_7035.png)

  硬件设计思路：
  - 电源部分使用 2 节 18650 电池供电，实测电压 8.4V。经过 PMOS 防反接进入 Mini 降压模块（5V）再通过 AMS1117-3V3 输出 3V3。5V 供电给四个 TT 马达，语音模块与舵机驱动；3V3 供电给 ST 最小系统板，自动下载电路与所有逻辑通信高电平。
  - 控制部分采用市面上成熟方案 STM32F103C8T6 最小系统板引出对应引脚排针，引出 UART1 供自动下载以及上位机通信；引出 SPI2 与 PS2 手柄进行通信，同时考虑到硬件 NSS（CS）有许多坑，故采用软件 NSS；引出 UART3 与舵机驱动芯片通信；引出 UART2 与语音模块通信；采用 TIM3 四个 PWM 通道控制左侧两个 TT 马达，可以自由的设置调节速度的方式，同时使用 TIM4 四个 PWM 通道控制右侧两个 TT 马达。
  - 布线部分注意了电源线加粗；信号线类差分走线，包地走线；保证 LDO 输入输出电容回路可在顶层回流到地；打缝合孔增强电气性能；修铜处理尖角和孤岛并保证地完整性。

- **9.27 晚**：歪比巴卜同学焊接了第一块板子并进行测试，选取比比拉布和奶龙大笑阴笑作为音频输出，测试 CH340 自动下载电路正常，测试舵机驱动芯片时发现 IIC 通信两根线画反了，飞线补救 🤓。

## 3. STM32 工程框架搭建

**功能描述**：使用 STM32CubeIDE 完成芯片选型、基础外设（SYS、RCC、时钟树、方向引脚）配置与工程生成，搭建后续功能开发所需的软件框架。

**开发历程**：

- **10.1**：电控刀盾同学千辛万苦重新下软件，把新老 ide、mx、vscode、clion 全配了一遍，鉴定为吃饱了撑的。
- **10.2**：刀盾跟着豆老师进行一些配置，搭工程框架。

  - **选芯片建项目**

    ![选芯片建项目](图片和附件/image%2010.png)

  - **配 SYS**
    1. 点左侧 **System Core**，点开下拉，选择 **SYS**
    2. 在右侧 SYS 配置面板：Debug 下拉框选择 **Serial Wire**；Timebase Source 保持 **SysTick** 不动

    ![配置 SYS](图片和附件/image%206.png)

  - **配置 RCC 外部高速晶振**
    1. 左侧 `System Core` → 点开 **RCC**
    2. 在右侧 RCC 面板：High Speed Clock (HSE) 下拉，选择 **Crystal/Ceramic Resonator**

    ![配置 RCC](图片和附件/image%207.png)

  - **调时钟树**：HCLK 那里直接输 72 然后 enter。

    ![调时钟树](图片和附件/image%209.png)

  - **配方向引脚**

    ![配方向引脚一](图片和附件/image.png)

    ![配方向引脚二](图片和附件/image%203.png)

  - **生成工程**：Code Generator 选项卡，generated files 全勾选。

    ![生成工程](图片和附件/image%201.png)

## 4. 麦轮底盘运动控制

**功能描述**：实现麦克纳姆轮（麦轮）底盘的运动控制，支持前进、后退、侧向移动等全向移动方式。

**开发历程**：

- **10.3 上电测**：试 n 多次失败 n 多次后终于想起来查看接线。回家手边没有万用表，于是用 TT 马达充当蜂鸣档万用表，发现电机不转是因为给 PCB 板供电的电池盒焊线时虚焊了，刀盾同学小发雷霆！

  ![上电测试](图片和附件/image%2011.png)

- **10.4**：也是发动人脉找到焊接工具，重焊了一遍电池盒。手边没有电表于是拿 TT 马达当蜂鸣档用了，测了发现通断方面没有问题。
- **10.5**：不信邪，把从打开 CUBEIDE 开始到烧录的所有操作录屏发给实训战队的电控组长求帮排查问题。向硬件要来板子文件之后，发现是电驱一直处于休眠状态，原来是硬件问题！电控刀盾同学勃然小怒！歇之。

## 5. 机械臂（舵机）控制

**功能描述**：通过 I2C 驱动 PCA9685 舵机驱动芯片，实现大臂、小臂、夹子三路舵机的角度映射、限位与上电归位，完成机械臂的精准控制。

**开发历程**：

- **10.10**：刀盾同学在 codex 老师指导下实现 I2C 驱动 PCA9685，实现大臂/小臂/夹子三路舵机的角度映射、限位与上电归位。遇到上电后机械臂干涉导致舵机卡死的问题，把舵盘拆了重装遂解决该问题。
